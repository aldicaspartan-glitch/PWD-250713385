BEASISWA UAJY

UAJY menyelenggarakan berbagai program BEASISWA dengan kriteria dan manfaat yanng berbeda -beda.

  • Beasiswa program serjana (S1), Yaitu program seleksi siswa berprestasi (PSSB), Beasiswa internasional (BPI), Beasiswa Program Akademik (BPA), dan lain-lain.
  • Beasiswa program Pascasarjana (S2), yaitu beasiswa prestasi (BPM), Beasiswa Magister Unggul (BMU), dan BIMA.
